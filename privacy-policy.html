Privacy Policy - MoneyPulse Video Bot

Last updated: September 2026

This application ("MoneyPulse Video Bot") is an automated video-generation and publishing tool operated by its developer for the sole purpose of uploading finance-related videos to a single, developer-owned YouTube channel.

What data this application accesses

This application uses the YouTube Data API v3 to upload video files, titles, descriptions, and tags to the developer's own YouTube channel. It does not access, read, or modify any other YouTube account's data, and does not access viewers' personal information, comments, or analytics beyond what is required to confirm a successful upload.

How data is used

Authentication credentials (OAuth tokens) are used exclusively to authorize automated video uploads to the developer's own channel on a scheduled basis. No data collected through this process is sold, shared, or used for any purpose other than operating this automation.

Data storage

OAuth credentials are stored as encrypted secrets within the developer's private automation environment (GitHub Actions Secrets) and are not accessible to any third party.

Third-party services

This application also uses the following third-party services solely to generate video content: a news headlines API, an AI text-generation API, a text-to-speech service, and a stock footage API. None of these services receive YouTube account data.

Contact

For any questions about this privacy policy, please contact the developer via the GitHub repository linked to this project.

This page is provided to satisfy Google OAuth verification requirements for the YouTube Data API.
